Bestimmen Sie aus den Abmessungen und der Masse einer Kartonrolle (z.B. von einer Rolle WC-Papier) deren konstante Fallgeschwindigkeit in Luft.

Falls Sie keine Rolle zur Hand haben, rechnen Sie mit einer Länge von \lRoO, einem Durchmesser von \dRoO\ und einer Masse von \mRoO. Die Rolle fällt quer, d.h. mit horizontaler Achse.
